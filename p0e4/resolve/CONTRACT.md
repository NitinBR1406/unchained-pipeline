# Resolve pre-install contract V01

`build(canonical, creative, byte_resolver, fps=(25,1))` invokes the existing
canonical validator/preflight consumer. It preserves all 14 groups, including
experiment/provenance and attribution identifiers; it makes no schema, approval,
financial, analytics or original-media changes. Source bytes and evidence must
resolve and match their SHA256. Deterministic plans contain parent hashes and
no anticipated output hash. Rendered output SHA exists only after actual bytes.

`verify` rebuilds the complete plan and compares canonical JSON bytes. Millisecond
times must map exactly to rational frame boundaries. Intervals are half-open.
Derivative windows clip source segments with an equal offset, preserving timing
without speed changes. Each derivative independently requires at least 80%
unobscured performance, even when the complete creative master already passes.

1080p landscape/portrait/square/4:5 profiles are internal review intentions, not
current social-platform delivery specifications. Codec support must be probed.
No remote output, cloud upload or social Quick Export is implemented.

Existing canonical effects carry only intensity and time. They do not specify
crop geometry, scale trajectories, shake seed/keyframes, caption words/styles,
transition handles or exact plugin presets. The plan preserves every field and
records missing parameters as blockers. Unsupported canonical operations fail
validation; transitions/text/Fusion requirements are inventoried but do not
silently expand the accepted canonical enum. Grade remains subject to the locked
baseline. No arbitrary shader/script/template execution is provided.

`execute` always raises. Product documentation distinguishes native GUI tools
from Studio scripting and externally computed intelligence, but no exact local
API is asserted. Installation, version/edition discovery, installed developer
documentation and a safe read-only capability smoke precede an execution adapter.
Nitin retains install/purchase and separate audio-binding decisions.

`review_candidate` hashes actual candidate bytes, plan and complete QC observations.
FAIL/UNKNOWN checks produce a hash-bound rework request; revised recommendations
must go through validation and planning again. Complete reported checks remain
`OBSERVATIONS_COMPLETE_AUTHENTICATED_QC_PENDING`. This helper cannot authenticate
the reviewer, prove Resolve execution or approve a master. Fresh independent QC
must use the established authenticated package-chain route on the actual output.

Free/Studio purchase requirements and source URLs are machine-readable in
`FREE_VS_STUDIO_REQUIREMENTS_V01.json`; operation distinctions are in
`CAPABILITY_MATRIX_V01.json`. All artifact fixtures are synthetic, not media.
