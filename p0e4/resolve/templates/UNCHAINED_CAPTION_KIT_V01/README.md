# UNCHAINED_CAPTION_KIT_V01

Reusable caption configuration for the verified MASTER 2 / V06 72-96 second private preview. The kit is configured but not rendered because Resolve FontManager does not currently expose Montserrat or Cinzel. Silent font fallback is forbidden.

`caption_kit.py` validates the font gate and hashes text, timing, styling, exact template identity, render settings and source binding so changed text cannot reuse stale output. Actual lyric mode remains HOLD until verified lyrics and timing exist.
