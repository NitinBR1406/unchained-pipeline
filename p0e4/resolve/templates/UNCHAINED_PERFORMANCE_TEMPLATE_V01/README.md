# UNCHAINED_PERFORMANCE_TEMPLATE_V01

Reusable Resolve project contract for hash-bound multi-take performance work. Source, alignment, edit, color and motion bindings are separate. All motion and caption switches are off by default. Enabling a motion component requires a Nitin-selected policy plus validated event evidence. V06 is retained only as the Aakhri provisional short-preview preset and is never treated as universal iPhone correction.

Run `python -m p0e4.resolve.performance_template JOB PLAN` through the wrapper or call `write_plan`. The dry-run never renders. The exported DRP is an isolated disposable instantiation used to verify HLG settings, media binding, base crops and bypassed component topology.
